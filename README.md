# 投递清单 · 医院求职管理 PWA

一个纯前端的求职投递管理工具，内置 44 家上海三区医院清单。
数据保存在手机本地，不上传任何服务器。

## 文件结构

```
index.html            页面入口
app.css               样式（iOS 风格）
app.js                交互逻辑
data.js               医院清单数据（可直接改）
manifest.webmanifest  PWA 配置
sw.js                 Service Worker（离线缓存）
icons/                应用图标
```

## 部署到 GitHub Pages

1. 新建一个仓库（例如 `hospital-tracker`）。
2. 把本文件夹内**所有文件**上传到仓库根目录：
   - 网页端直接拖拽上传即可；
   - 或用命令行：
     ```bash
     git init
     git add .
     git commit -m "init"
     git branch -M main
     git remote add origin https://github.com/<你的用户名>/hospital-tracker.git
     git push -u origin main
     ```
3. 仓库页 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** →
   Branch 选 `main`、目录选 `/ (root)` → **Save**。
4. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/hospital-tracker/`。

> 全部使用相对路径，放在子路径（`/hospital-tracker/`）下也能正常工作。


## 自动监测招聘岗位

项目里带了一个每天自动运行的定时任务（GitHub Actions），
数据来自**上海卫生人才网**（`rczp.shwshr.cn`）的公开岗位接口。

- **频率**：每天北京时间 8:30 和 18:30 各查一次
- **范围**：清单里的医院 + 岗位名含「护理」+ 仍在报名期内
- **结果**：写入 `notices.json`，App 首页顶部那条提示点击可看全部在招岗位
- **发现新增**：提示条会变成橙色「新增 N 个岗位」，并在下次打开时标「新」

推送开关：默认不推送，只更新文件。想要微信收提醒，加一个 Secret 即可。

### 开启微信推送（可选，5 分钟）

1. 打开 <https://sct.ftqq.com>，微信扫码登录，复制你的 **SendKey**
2. 进入仓库 **Settings → Secrets and variables → Actions → New repository secret**
3. Name 填 `SERVERCHAN_KEY`，Secret 粘贴 SendKey，保存
4. 之后每次有新增岗位，微信会收到一条汇总消息

用企业微信群机器人也行：Secret 名填 `WECOM_WEBHOOK`，值是机器人的 webhook 地址。

### 手动跑一次

仓库 **Actions** 页 → 左侧「医院招聘监测」→ 右侧 **Run workflow**。

### 覆盖边界（重要）

| 能监测 | 监测不到 |
|---|---|
| 市卫生人才网上发布的医院自主招聘岗位 | 区统招公告（浦东、宝山、杨浦的批次通知） |
| 全年随时更新，每天两次 | 只在医院自己官网上挂的招聘 |

区统招是另一条通道：浦东一般每年 3 月一批（`ggzp.pudong.gov.cn`），
宝山 5 月和 9 月（`rczp.shwshr.cn` 的区统招公告），杨浦分上下半年。
这几个是政府网站，页面靠 JS 渲染、结构常变，抓起来不稳定，
**更稳的做法是在手机日历里给 2 月底、4 月底、8 月底各设一个提醒**，
到点手动刷一遍，比写爬虫可靠。

### 改监测条件

编辑 `scripts/monitor.mjs` 顶部的两个常量：

```js
const KEYWORDS = ['护理'];   // 想监测的岗位关键词，可加 '护师'、'临床护理'
```

匹配哪家医院由 `data.js` 里的清单自动决定——**往清单里加医院，监测范围自动扩大**。

## 添加到手机主屏幕

**iPhone / iPad**：用 **Safari** 打开链接 → 底部「分享」按钮 → 「添加到主屏幕」→ 添加。
（必须用 Safari，微信内置浏览器和 Chrome iOS 不支持添加到主屏幕。）

**Android**：用 Chrome 打开 → 右上角菜单 → 「安装应用」。

添加后从桌面图标打开，是全屏无地址栏的独立窗口，断网也能用。

## 怎么用

- **清单页**：44 家医院按「主投 / 可冲 / 备选」分组。
  顶部可按优先级、状态、关键词筛选。
- **点开任意医院**：
  - 点状态按钮（未投 / 已投 / 筛选中 / 面试 / Offer / 未通过 / 不投）即可更新；
  - 填投递日期后自动变成「已投」，并默认 7 天后提醒跟进；
  - 投递渠道可多选，用于后面统计哪种渠道有效；
  - 「复制」按钮可一键复制邮箱、电话或整条投递信息。
- **进度页**：已投 / 有回应 / 进面 / Offer 的漏斗、进面率、
  「该跟进了」（逾期或投递 7 天无更新的会自动列出）、渠道效果、区域分布。
- **设置页**：导出 / 导入 JSON 备份、清空记录。

## 修改医院清单

两种方式：

1. **App 内**：清单页右上角 `+`，手动添加（保存在本机）。
2. **改代码**：编辑 `data.js`，按现有格式增删条目，字段含义：

   | 字段 | 说明 |
   |---|---|
   | `id` | 唯一数字，不要重复 |
   | `name` | 医院名称 |
   | `level` | 分级，如 三级甲等 |
   | `priority` | 主投 / 可冲 / 备选 |
   | `district` | 所在区域 |
   | `address` | 地址 |
   | `hiring` | 在招 / 常年招 / 本批已结束 |
   | `channel` | 投递途径（原文） |
   | `url` | 投递链接 |
   | `note` | 门槛与备注 |
   | `email` / `phone` | 有则显示复制按钮 |
   | `guessChannels` | 默认渠道标签 |

## 数据说明

- 所有记录（状态、日期、渠道、备注）存在浏览器 localStorage，键名 `hmt.records.v1`。
- **换手机、换浏览器、清除网站数据都会丢失**，请定期在设置页导出备份。
- 每次打开都会走网络拿最新文件，断网时用本地缓存，改完代码推上去刷新即可生效。

## 小提示

iOS 上 PWA 不能可靠地发本地通知（需要推送服务器），
所以「提醒」用进度页的「该跟进了」列表替代——打开 App 就能看到哪些逾期了。
